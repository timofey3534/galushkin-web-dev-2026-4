# Лабораторная 4 — теория для защиты

Рендер блюд через JavaScript: массив данных, DOM, `data-*`,
сортировка, выбор и сумма заказа.

## Массив блюд (`js/dishes.js`)

- Каждый объект: `keyword` (латиница, уникален — ключ для сервера),
  `name`, `price` (число, не строка — чтобы складывать),
  `category` (`soup`/`main`/`drink`), `count`, `image` (путь без
  расширения). Отдельный файл = данные отдельно от логики.

## DOM и рендер (`js/display.js`)

- `document.getElementById` — найти контейнер секции,
  `document.createElement('div')` — создать карточку,
  `classList.add`, `dataset.dish = keyword` — `data-dish` атрибут
  для связи карточки с объектом, `append` — вставить в страницу.
- `textContent` (не `innerHTML`) — безопасно вставляет текст.
- `filter` — отобрать блюда категории, `sort(compareByName)` —
  сортировка по алфавиту перед выводом, `forEach` — перебор.
- Компаратор возвращает -1/0/1: меньше/равно/больше.
- Скрипты в конце `<body>` — DOM уже построен, слушать
  `DOMContentLoaded` не нужно. Порядок важен: сначала данные,
  потом рендер, потом заказ.

## Выбор и заказ (`js/order.js`)

- Состояние — объект `order = { soup: null, ... }`, `null` = не выбрано.
- Клик по «Добавить»: `closest('.dish')` находит карточку кнопки,
  `dataset.dish` даёт keyword, `find` ищет объект в массиве,
  кладём в `order[category]` — повторный выбор той же категории
  перезаписывает (вместо Гаспачо станет другой суп).
- Подсветка: `classList.toggle('selected', условие)` — рамка как
  при hover, только выбранной карточке своей категории.
- Сводка: `null` → «Блюдо/Напиток не выбран», иначе «название цена».
  `hidden` показывает/прячет блоки: пусто — только «Ничего
  не выбрано», иначе категории + «Стоимость заказа».
- Сумма: проход по значениям объекта, `total += dish.price`.
- Скрытые поля `<input type="hidden" name="soup">` — при отправке
  на httpbin уходят `keyword`, видимых селектов больше нет.

## `const` / `let`, функции

- `const` — нельзя переназначить (массив/объект менять внутри можно),
  `let` — счётчики. `var` не используем (всплытие, function-scope).
- `function` declaration всплывает, поэтому вызовы внизу файла
  видят функции выше.

## ESLint

- Проверяет стиль: отступ 4 пробела, `;`, пробелы вокруг операторов,
  длина строки ≤ 80. Запуск: `npx eslint js/`.

## Что могут спросить

1. Что такое DOM? — дерево объектов страницы, API для изменения.
2. Зачем `data-dish`? — связать карточку с объектом без глобалок.
3. Чем `textContent` лучше `innerHTML`? — без XSS, только текст.
4. Как работает sort с компаратором? — -1/0/1 задают порядок.
5. Что будет при выборе второго супа? — перезапись в `order.soup`.
6. Как считается сумма? — `totalPrice` суммирует выбранное.
7. Что уходит на сервер? — keyword через hidden-поля + остальные поля.
8. Почему скрипты внизу body? — DOM готов, порядок выполнения.
